⚡ Option 1: One-Line Automatic Setup (Recommended)

Automatically installs the 4096-bit RSA GPG key to /etc/apt/keyrings/arda-tech.gpg, registers /etc/apt/sources.list.d/arda-tech.list, and refreshes your APT package index: 

$ curl -fsSL https://antux912012.github.io/arda-tech-ppa/setup.sh | sudo bash
🔧 Option 2: Manual Step-by-Step APT Configuration

Standard Debian/Ubuntu keyring configuration without apt-key deprecation warnings: 

sudo mkdir -p /etc/apt/keyrings
curl -fsSL https://antux912012.github.io/arda-tech-ppa/KEY.gpg | sudo tee /etc/apt/keyrings/arda-tech.gpg >/dev/null
echo "deb [signed-by=/etc/apt/keyrings/arda-tech.gpg] https://antux912012.github.io/arda-tech-ppa stable main" | sudo tee /etc/apt/sources.list.d/arda-tech.list
sudo apt update
